# Web Designing Lab

## Experiment 1: GitHub Repository and GitHub Pages

### Aim
To create a GitHub repository, manage branches, merge changes, and publish a simple webpage using GitHub Pages.

### Software and Tools Used
- Visual Studio Code
- Git and GitHub
- HTML
- CSS
- Web Browser

### Procedure
1. Created a GitHub repository for the web designing lab.
2. Added the required HTML and CSS files.
3. Created a new branch to make changes.
4. Merged the changes into the main branch.
5. Used GitHub Pages to host the webpage.

### Result
Successfully created a GitHub repository and learned the basic operations of branch creation, merging, and website hosting using GitHub Pages.
